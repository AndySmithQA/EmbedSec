# Delegate lab

| Path | What it is |
|---|---|
| `lab-guide.md` | Step-by-step delegate lab guide (Exercises 0–6). |
| `delegate-worksheet.md` | Worksheet for the ticket-to-PR trace. Delegates complete it during the lab. |
| `starter/` | The starter repository. Publish it as a **template repository** on GitHub and share the link with delegates. |

The starter contains the customer portal API, the `security-requirements-and-evidence` Copilot skill, the CI workflow with the PR evidence gate, the PR template, and two tickets: TICKET-101 (the lab) and TICKET-102 (the transfer exercise).

It deliberately does **not** contain `.github/copilot-instructions.md` or the export feature. Delegates create both.
The reference solution is in `../instructor/lab-solution/`. Do not share it with delegates.
