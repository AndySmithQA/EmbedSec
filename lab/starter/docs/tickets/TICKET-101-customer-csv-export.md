# TICKET-101: Export customers to CSV

**Type:** Feature  
**Requested by:** Customer Success  
**Priority:** High

## Story

As a portal user, I want to export our customer list to CSV so that I can work with it in a spreadsheet.

## Notes from the requester

- Add an "Export" button to the customer list page. The front end team will handle the button.
- We need an API endpoint that returns the file.
- Include all the customer details so we don't have to come back and add columns later.
- It should be quick to build. Copilot can probably write it in five minutes.

## Acceptance criteria

- [ ] Clicking export downloads a CSV of customers.
- [ ] The CSV opens in Excel.
